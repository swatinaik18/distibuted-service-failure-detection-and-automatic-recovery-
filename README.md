Distributed Service Failure Detection and Automatic Recovery System

Introduction

This project is developed to detect failures in distributed services and perform automatic recovery. It monitors services, identifies failures, and attempts to restore failed services without manual intervention.

Objectives

- Monitor the health of services.
- Detect service failures.
- Perform automatic recovery.
- Maintain service availability.
- Record failure and recovery history.

Features

- Service health monitoring
- Automatic failure detection
- Automatic recovery mechanism
- Service status monitoring
- Recovery history tracking

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

Project Modules

- Backend
- Frontend
- Service Monitoring
- Recovery Manager

Working

1. The system monitors the services.
2. It checks whether services are running or not.
3. When a service fails, the system detects the failure.
4. The recovery manager attempts to recover the failed service.
5. Recovery details are recorded in the history.

Expected Outcome

The system helps detect service failures and automatically recover services, improving the reliability and availability of the system.

Conclusion

This project demonstrates service monitoring, failure detection, and automatic recovery in distributed systems.
